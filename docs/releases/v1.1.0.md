# rubbish-cleaner v1.1.0

## Release highlights

- Run scan, cleanup, and verification across multiple fixed drives, with checkpoint/resume support for scan and cleanup.
- Schedule policy-based cleanup runs and use platform-aware drive resolution, default paths, and PowerShell host selection on Windows, Linux, and macOS.
- Improve safe cross-platform behavior for POSIX links, locked items, root-temp discovery, and Windows PowerShell 5.1 parsing.

## Verified test scope

- 55 Pester tests
- 14 parsed PowerShell files
- Nine sandbox suites
- GitHub Actions CI on Windows, Ubuntu, and macOS
- Full test entry on Windows PowerShell 5.1
