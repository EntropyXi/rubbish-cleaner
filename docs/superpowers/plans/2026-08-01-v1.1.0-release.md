- [ ] **Step 1: Validate tracked Markdown links**

Run this read-only PowerShell link checker over all tracked `*.md` files. It resolves relative links and local image targets against each document directory and ignores remote URLs and anchors:

```powershell
$missing = @()
foreach ($file in @(git ls-files '*.md')) {
    $text = Get-Content -LiteralPath $file -Raw -Encoding UTF8
    foreach ($match in [regex]::Matches($text, '\[[^\]]+\]\((?<target>[^)]+)\)')) {
        $target = $match.Groups['target'].Value.Trim()
        if ($target -match '^(https?://|#|mailto:)' -or $target -match '^<https?://') { continue }
        $pathPart = [uri]::UnescapeDataString(($target -split '#', 2)[0]).Trim('<', '>')
        if (-not $pathPart) { continue }
        $resolved = Join-Path (Split-Path -Parent $file) $pathPart
        if (-not (Test-Path -LiteralPath $resolved)) { $missing += "$file -> $target" }
    }
}
if ($missing.Count -gt 0) { $missing; exit 1 }
```
